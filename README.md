# HL_formula_learning

一个用于逐层讲解科研与数学公式原理的 Codex skill。

它会把公式从必要的前置知识和直观理解开始，逐步推进到符号定义、公式结构、推导依据、适用条件和具体计算示例；对于空间或几何概念，在确实有帮助时补充简单易懂的原理示意图。

## 适用场景

当你提出以下类型的问题时，可以使用本 skill：

- “讲解公式原理”
- “理解公式原理”
- “这个公式讲的是什么”
- “请解释这个科研公式中的每一项”
- “这个公式为什么这样写”

它尤其适合物理、数学、机器学习、信号处理、控制、计算机视觉和其他科研场景中的公式理解。

## 主要工作流程

1. 确认目标公式和用户想解决的问题。
2. 补充理解公式所需的最少前置知识。
3. 从直观含义逐层过渡到数学表达。
4. 定义每一个符号、下标、运算符、单位和约束条件。
5. 解释公式为什么采用这种结构，以及每一项的作用。
6. 说明推导、假设、适用范围和常见误解。
7. 使用具体数值进行完整计算，并解释最终结果。
8. 对空间或几何概念，在必要时生成清晰的原理示意图。

## 使用方式

### 自动触发

直接提出公式原理相关问题即可，例如：

```text
请讲解 Tucker 分解的原理，并说明核心张量和因子矩阵分别做什么。
```

### 显式调用

```text
$hl-formula-learning 请解释交叉熵损失函数。
```

## 示例问题

```text
讲解傅里叶变换公式中每个符号的含义，并用一个简单信号举例。
```

```text
这个梯度下降公式为什么能够找到函数最小值？请从几何直觉开始解释。
```

```text
请解释旋转矩阵，并画一个二维向量旋转前后的示意图。
```

## 安装

将整个 `hl-formula-learning` 文件夹复制到 Codex 的用户技能目录：

```text
~/.codex/skills/hl-formula-learning/
```

Windows 用户通常可以使用：

```text
%USERPROFILE%\\.codex\\skills\\hl-formula-learning\\
```

安装后重新打开或刷新 Codex，使技能列表重新加载。
